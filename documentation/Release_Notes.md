# FinSight Release Notes

## Version

- Product: FinSight
- Version: 1.0.0
- Date: May 14, 2026

## Included Features

- Local account registration and login
- Transaction CRUD
- Budget tracking
- Dashboard analytics
- CSV import
- OCR-assisted transaction capture
- AI assistant with fallback and optional local runtime
- Windows native integrations

## Known Limitations

- No bank API integration
- OCR quality depends on source image quality
- Local model features require compatible runtime assets
